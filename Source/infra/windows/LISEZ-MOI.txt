Serveur du magasin : installation et mise à jour
(Windows 10 ou 11, 64 bits ; dossier construit par l'outil de distribution, T-080)

Première installation
1. Sur la box : donner au serveur une adresse fixe (celle du paramètre LAN_IP).
2. Copier ce dossier sur le serveur, par exemple C:\VenteWeb (pas sur le Bureau).
3. Double-clic sur « Installer ou mettre a jour.cmd », accepter la demande d'administrateur.
4. À la fin : choisir l'identifiant et le nom du premier admin ; noter le mot de passe
   provisoire affiché (il ne sera plus montré).
5. Avec un nom de domaine : sur la box, DHCP, serveur DNS = l'adresse du serveur. Les
   tablettes ouvrent alors l'adresse affichée à la fin de l'installation (https://...).
   Sans nom de domaine (réseau du magasin seulement) : sur chaque tablette, téléphone ou PC,
   une seule fois, ouvrir http://<adresse du serveur> et suivre la page (installer le
   certificat du magasin), puis « Ouvrir l'application » (https://<adresse du serveur>).

Mise à jour
1. Copier le nouveau dossier à côté de l'ancien (exemple : C:\VenteWeb-2).
2. Double-clic sur son « Installer ou mettre a jour.cmd ». La base est sauvegardée avant
   toute modification (C:\ProgramData\VenteWeb\sauvegardes).
3. Quand tout marche, supprimer l'ancien dossier.

Les données ne sont jamais dans ce dossier : C:\ProgramData\VenteWeb (base, factures,
sauvegardes, certificats, journaux, paramètres et secrets).

En cas d'échec : le message dit quelle étape a échoué ; les journaux sont dans
C:\ProgramData\VenteWeb\journaux. Relancer le script après correction ne casse rien.

Sauvegardes
- Automatiques toutes les 15 minutes : sur ce PC (C:\ProgramData\VenteWeb\sauvegardes), sur
  le disque externe s'il est branché et, si le magasin a un coffre OVH, chiffrées dans ce
  coffre quand Internet répond.
  Journal : C:\ProgramData\VenteWeb\journaux\sauvegarde.log
- « Sauvegarder.cmd » : une sauvegarde tout de suite (avant une manipulation risquée).
- Avec un coffre OVH : le mot de passe des sauvegardes chiffrées, affiché à l'installation,
  se garde sur une enveloppe scellée hors du magasin ; sans lui, le coffre est illisible.

Restauration
- « Restaurer.cmd » : choisir une sauvegarde de la liste (ou O : la plus récente du coffre
  OVH), puis taper RESTAURER. La base actuelle est d'abord sauvegardée (avant-restauration-*).
- Serveur perdu : sur un PC neuf avec la même adresse fixe, copier ce dossier,
  « Installer ou mettre a jour.cmd », puis « Restaurer.cmd », choix O, mot de passe de
  l'enveloppe. Les tablettes retrouvent l'application à la même adresse.
